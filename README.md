# 🍔 FIAPressa - Cardápio Digital

O **FIAPressa** é um aplicativo mobile desenvolvido em **React Native** com **Expo Router**, focado na agilidade do atendimento para lanchonete da faculdade. O projeto permite navegar entre categorias, visualizar detalhes de produtos e gerenciar o status de pedidos de forma intuitiva.

---

## 🚀 Tecnologias Utilizadas

* **React Native**: Framework para desenvolvimento mobile.
* **Expo & Expo Router**: Estrutura de navegação baseada em arquivos.
* **JavaScript (ES6+)**: Linguagem base do projeto.
* **StyleSheet**: Para estilização nativa.

---

## 📱 Funcionalidades

1.  **Home (index.js)**: Tela inicial com categorias e destaques do dia.
2.  **Navegação (_layout.js)**: Estrutura de rotas em Stack para fluidez entre telas.
3.  **Cardápio (details.js)**: Listagem detalhada de itens com opção de adição ao carrinho.
4.  **Perfil (profile.js)**: Informações do usuário e acompanhamento de pedidos em tempo real.

## 🛠️ Como rodar o projeto

1.  Clone o repositório:
    ```bash
    git clone https://github.com/MUnizZz526/fiapressa.git
    ```
2.  Entre na pasta:
    ```bash
    cd fiapressa
    ```
3.  Instale as dependências:
    ```bash
    npm install
    ```
4.  Inicie o Expo:

    ```bash
    npx expo start
    ```
